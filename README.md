# UniLifeNovel

## Apie žaidimą

Tai vizualinės novelės tipo žaidimas, kuriame žaidėjas seka universiteto studento gyvenimą per įvairų dialogą, pasirenkantis įvairius sprendimus kurie gali daryti įtaką žaidimo istorijos eigai.

## Instaliacijos instrukcijos

1. Atsisiūsti "UniNovel" zip failą.
2. Išarchyvuoti ir viduje jo paleisti UniLife.exe failą.
3. Žaisti :D

## \## 📌 Overview



\*\*UniLifeNove\*\* is a modular narrative system built in Unity that focuses on flexible storytelling mechanics.  

The project includes dialogue management, branching decisions, persistent variables, save/load functionality, and a simple internal QA testing setup.



It is designed as a learning project to simulate real game development structure with systems separation and testability in mind.



\---



## \## 🧱 Core Systems



## \### 💬 Dialogue System

\- Displays narrative text

\- Supports sequential dialogue flow

\- Integrates with choices and variables



\---



## \### 🌿 Choices / Branching

\- Player decisions affect story paths

\- Branch-based narrative structure

\- Supports conditional outcomes



\---



## \### ⚙️ Variables \& Conditions

\- Global and local variables

\- Condition-based dialogue and choices

\- Used for story progression logic



\---



## \### 💾 Save / Load System

\- Full game state saving

\- QuickSave / QuickLoad functionality

\- Stores variables, chapter progress, and player state



\---



## \### 📖 Chapter System

\- Structured story progression

\- Chapter-based scene management

\- Supports replay and transitions



\---



## \### 🎯 Mini Objectives

\- Lightweight objective tracking

\- Used for guiding player progression

\- Updates dynamically based on game state



\---



## \### 🗂 Backlog System

\- Development tracking structure

\- Organizes planned features and tasks

\- Helps manage iterative development



\---



## \### 🧪 Testing System

\- Acceptance test framework implemented in Unity

\- Automated test execution for core systems

\- Includes:

&#x20; - Dialogue tests
